# 保真差异与未解决事项

本项目只能称为“金巅模型策略适配复现版本（公开数据代理版）”，不能称为严格复现。

## 已明确的差异

- 原始材料没有完整生产代码、原数据库快照、精确逐日目标仓位或可独立核验的历史输出。
- 正式行情代理为 RQAlpha 免费 bundle，而非原 Wind/聚宽环境；复权、参考前收盘、停牌和证券身份口径可能存在差异。
- 历史成分由官方公告事件式重建，而非原策略使用的成分数据库快照。它满足 point-in-time 与可追溯要求，但无法证明与原数据库的所有入库时间完全一致。
- 连续状态遇零值/缺失时重置、零信号延续、现金20%、T+1收盘执行和5 bps成本属于公开披露的工程化解释。
- 指数收盘价作为多空袖套收益代理，未建模期货保证金、融券券源、税费、冲击成本、容量或现金利息。
- 50/50基准、风险指标、迁移审计和HTML报告属于验收扩展，并非原策略规则。

## 已量化的数据差异

RQAlpha 与只读 BaoStock 对照覆盖1092只共同证券及1,394,540条记录。开收盘价格在0.1%容差内比例均为99.99971%，前收盘为99.99735%；两个核心方向因子一致率分别为100%和99.99749%，停牌一致率99.99993%，最终50/500方向信号一致率99.37231%。

差异主要来自独立报价舍入、公司行为参考价处理及少量数据覆盖边界。生产实现不要求逐点价格完全相同，但任何低于配置阈值的核心方向或停牌一致率都会失败。

## 尚未能确认

- 原材料中的“窗口内最长连续段”与“当前连续状态”存在歧义；本实现采用当前连续状态并封顶5日。
- 原策略在临时停牌、复牌参考价、代码/主体变更和极端公司行为上的完整人工处置规则不可得。
- 十档数值能从现有材料恢复，但无法证明与所有历史生产版本完全一致。

因此，后续即使更换 bundle 版本或扩大样本，也必须保留 `adapted`/`unresolved` 标签并重新运行迁移门禁，不能升级描述为严格复现。
