## 因子与信号

股票 `i` 在交易日 `t` 的两个输入为：

```text
x1(i,t) = close(i,t) - open(i,t)
x2(i,t) = close(i,t) - preclose(i,t)
```

正值连续状态为 `1...5`，负值为 `-1...-5`，绝对值封顶5；零值或无有效交易输入重置为0。十档映射为：

```text
 5:  50.33223    4:  25       3:  8.3      2:  4.6342   1:  0.7465
-1:  -0.873     -2:  -4.234  -3: -9.88764 -4: -25      -5: -50.8763
```

每个指数对当日有效成分取截面均值，再取3个交易日简单移动平均 `E50(t)`、`E500(t)`。方向由下式符号决定：

```text
[E50(t)-E50(t-1)] - [E500(t)-E500(t-1)]
```

## 时点成分

历史成分由当前官方成分锚点反向回放全部已配置的定期和临时调样事件。调样只在生效日应用，公告日不提前生效；上证50/中证500在每个有效快照必须分别为50/500只。公告缺失、解析失败、重复证券、来源冲突或数量异常都会终止。

2015-05-20 的同页双临时事件是明确回归用例：上证50同时执行 `601299→600893` 与 `600832→600583`。这一修正使正式历史证券总数从错误的1457恢复为1458。

## preclose 与停牌

`preclose` 不等同于简单 `shift(close)`：普通交易日使用前一真实收盘；现金分红/拆并股使用 RQAlpha 公司行为记录计算可比前收盘；复杂公司行为与停牌后参考价重置只有在被分类且 bundle 提供明确参考值时才允许受控回退。任何无法解释的显著差异失败关闭。

停牌来自 `suspended_days.h5`，不以成交量为0或数据缺失替代。证券生命周期校验分别标记上市前、正常交易、停牌、退市后与未知缺失。

## 反未来函数时序

1. T日收盘后，以截至T日可见的行情与生效成分计算信号。
2. T到T+1收盘收益由旧持仓获得。
3. T+1收盘按T日目标权重成交并扣除成本。
4. 新权重从T+1到T+2收盘区间开始贡献收益。

`trades.csv` 同时保存 `signal_date` 与 `execution_date`；测试要求后者是前者之后的第一个真实交易日。

## 指标

单边成本为 `0.0005 × Σ|w_new-w_old|`。指标包含总收益、年化收益、年化波动、Sharpe（无风险利率0）、Calmar、最大回撤及持续期、换手、成本、基准及超额收益、跟踪误差和信息比率。基准为上证50与中证500指数收盘收益各50%。
